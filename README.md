# 프린세스 메이커 2 리파인 모드

**프린세스 메이커 2 리파인 Steam 한국어판**에 회차 플레이와 새로운 성장 선택지를 추가하는 모드입니다.


## 설치 방법

1. 게임을 종료한 뒤, 릴리즈에서 `pm2-refine-mods-v<버전>.zip` 파일을 다운로드하고 압축을 풉니다.
2. Steam 라이브러리에서 게임을 우클릭하고 **관리 → 로컬 파일 탐색**을 선택합니다.
3. 게임 폴더 안에 기존 `msimg32.dll` 파일이 있다면, 덮어쓰기 전에 별도 폴더에 미리 백업해 둡니다.
4. 압축을 푼 폴더를 열고 `msimg32.dll` 파일을 찾습니다. 이 파일을 2번에서 연 게임 폴더에 복사합니다. 복사 후 `pm2.exe`와 `msimg32.dll`이 같은 폴더에 나란히 있어야 합니다.
5. 압축을 푼 폴더의 `pic` 폴더를 엽니다. 안에 있는 `pm2mod_`로 시작하는 `.dat` 파일을 모두 선택해 복사합니다.
6. 게임 폴더에 원래 있던 `pic` 폴더를 열고, 5번에서 복사한 `.dat` 파일을 붙여넣습니다. 같은 이름의 파일을 바꿀지 물으면 **대상 폴더의 파일 덮어쓰기**를 선택합니다. 기존 `pic` 폴더를 삭제할 필요는 없습니다.
7. 압축에 있는 `pm2mod-installed.txt`도 `pm2.exe` 옆에 복사합니다. 이 파일은 다음 업데이트에서 구버전 모드 파일을 정리하는 데 사용합니다. `refine_data` 폴더가 포함돼 있다면 게임 폴더에 같은 이름의 폴더를 만들고, 그 안의 파일도 같은 위치에 복사합니다.
8. 아래 구조처럼 파일이 들어갔는지 확인한 뒤, 평소처럼 Steam에서 게임을 실행합니다.

설치 후 폴더 구조 예시:

```text
Princess Maker 2 Refine
├─ pm2.exe
├─ msimg32.dll                 ← 압축에서 복사한 파일
└─ pic
   ├─ (기존 게임 리소스 파일들)
   ├─ pm2mod_girl_common.dat   ← 압축의 pic 폴더에서 복사한 파일
   └─ pm2mod_girl_vanilla.dat  ← 압축의 pic 폴더에서 복사한 파일
```

즉, DAT 파일의 위치는 `Princess Maker 2 Refine\pic\파일명.dat`입니다. `pic` 안에 다시 `pic` 폴더를 만들지 마세요. 배포 버전에 따라 DAT 파일 수가 다를 수 있으므로, 압축의 `pic` 폴더에 포함된 파일은 모두 복사합니다.

기본 설치 경로:

```text
C:\Program Files (x86)\Steam\steamapps\common\Princess Maker 2 Refine
```

## 주요 수정사항

### 회차 플레이

- 엔딩 이후 회차 포인트와 획득 기록을 이어받아 새로운 회차를 시작할 수 있습니다. 회차 정보는 각 세이브 계보별로 관리됩니다.
- 엔딩, 이벤트 성공, 평가 보상 획득 등에 회차 포인트를 지급합니다. 같은 보상은 회차당 한 번만 지급합니다.
- 능력치·평가 보너스, 시작 아이템, 상점 해금 등 회차 옵션을 추가했습니다. 아이템 옵션은 해당 세이브 계보에서 한 번 이상 획득한 아이템만 표시됩니다.
- 엔딩이 끝나면 회차 시작용 기록을 저장할 수 있습니다. 불러오기 화면에서 해당 기록을 선택하면 다음 회차를 준비할 수 있습니다.
- 다음 회차는 기존 딸의 이름·생일·혈액형을 유지해 시작하거나, 옵션으로 새 캐릭터를 생성할 수 있습니다. 회차 시작 시 오프닝은 건너뜁니다.
- 회차 옵션으로 시작 소지금을 늘리거나 소지품 용량을 확장할 수 있습니다.

### 아이템과 상점

- 모드 전용 아이템과 상점 품목을 추가했습니다.

### 교육

- 고급 다음 단계로 `전문가` 교육 단계를 추가했습니다

### 아르바이트와 무사수행

- 아르바이트 등급을 확장하고, 등급별 보수를 조정했습니다.
- 무사수행에서 적을 쓰러뜨렸을 때 받는 골드 보상을 조정했습니다.

### 이벤트

- 집과 마을을 반복 이동하며 길거리 결투를 계속 발생시킬 수 있던 문제를 수정했습니다. 결투 요청은 게임 내 한 달에 한 번만 발생합니다.
- 동부 엘프의 노목 능력치 교환은 회차당 한 번만 성공할 수 있습니다.

### 화면 표시와 안정성

- 아이템 목록과 장비 상세창의 아이콘·텍스트 간격을 조정하고, 긴 이름과 효과 문구의 표시를 개선했습니다.
- 교육 선택 목록의 등급·수강료 표시 간격과 크기를 조정했습니다.

## 주의사항

- 이 모드는 **프린세스 메이커 2 리파인 Steam 한국어판에서만 적용할 수 있습니다.** DOS판·다른 리메이크·타 플랫폼 버전에는 적용할 수 없습니다.

- **모드 세이브는 바닐라 버전과 호환되지 않습니다.** 세이브 파일이 손상되면 진행 상황을 복구하지 못할 수 있으므로, 모드를 설치하거나 업데이트하기 전에 기존 세이브 파일을 별도 폴더에 반드시 백업해 주세요. 백업본은 모드를 적용한 세이브로 덮어쓰지 말고 보관해 주세요.
